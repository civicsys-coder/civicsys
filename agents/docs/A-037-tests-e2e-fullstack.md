# A-037 · E2E fullstack

## Por qué importa
El [DoD del Sprint 1](../../docs/sprints/sprint1.md) exige **un test E2E que conecte API + blockchain real (local)**. Sin este test, mockear todo en unit tests puede ocultar bugs de integración (ABI mal cargado, dirección equivocada, etc.).

## Conceptos clave
- **Hardhat node en background**: levantamos `npx hardhat node` antes del test y desplegamos.
- **Cleanup**: matar el node después.
- **Marker `e2e`**: para no correrlo en cada commit. Solo en CI nightly o pre-PR.

## Pre-requisitos
- [ ] [A-034](./A-034-tests-api-integration.md), [B-014](../../blockchain/docs/B-014-script-deploy.md) cerradas.

## Paso a paso

### 1. Crear `tests/e2e/test_fullstack.py`
```python
"""E2E real: hardhat local + API.

Pre-condiciones (manual o via fixture):
1. `cd blockchain && npx hardhat node` corriendo en :8545
2. `cd blockchain && npx hardhat run scripts/deploy.ts` ejecutado
3. `agents/.env` apunta a localhost:8545 con las direcciones del deploy
"""
import json
import time
from pathlib import Path

import pytest
from httpx import ASGITransport, AsyncClient


pytestmark = pytest.mark.e2e


@pytest.mark.asyncio
async def test_register_create_vote_close_report(monkeypatch):
    # Cargar direcciones del deploy
    dep_file = Path(__file__).parents[3] / "blockchain" / "deployments" / "hardhat.json"
    if not dep_file.exists():
        pytest.skip("hardhat.json no existe — ejecutá blockchain/scripts/deploy.ts primero")
    dep = json.loads(dep_file.read_text())
    monkeypatch.setenv("RPC_URL", "http://localhost:8545")
    monkeypatch.setenv("CHAIN_ID", "31337")
    monkeypatch.setenv("CITIZEN_REGISTRY_ADDRESS", dep["CitizenRegistry"]["address"])
    monkeypatch.setenv("VOTE_CONTRACT_ADDRESS", dep["Vote"]["address"])
    # Usar la deployer key local (NUNCA mainnet)
    monkeypatch.setenv("SIGNER_PRIVATE_KEY", "0x" + "ac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80")  # Hardhat #0
    monkeypatch.setenv("PUBLIC_SALT", "ssc-antipereza-2026-publico")
    monkeypatch.setenv("ANTHROPIC_API_KEY", "sk-fake")
    from api.config import get_settings
    get_settings.cache_clear()  # type: ignore[attr-defined]
    from api.services.blockchain_client import reset_blockchain_client
    await reset_blockchain_client()

    from api.main import create_app
    app = create_app()

    async with AsyncClient(transport=ASGITransport(app), base_url="http://test") as ac:
        # 1. Register
        r = await ac.post("/auth/register", json={"dni": "12345678", "full_name": f"Test {time.time_ns()}"})
        assert r.status_code == 201
        citizen_id = r.json()["citizen_id"]

        # 2. Create proposal
        deadline = int(time.time()) + 3600
        r = await ac.post("/proposals", json={
            "title": "E2E test proposal",
            "description": "Generated by E2E test",
            "options": ["A", "B"],
            "deadline": deadline,
        })
        assert r.status_code == 201, r.text
        proposal_id = r.json()["proposal_id"]

        # 3. Vote
        r = await ac.post(f"/proposals/{proposal_id}/vote", json={"citizen_id": citizen_id, "option": 0})
        assert r.status_code == 201, r.text

        # 4. Results
        r = await ac.get(f"/proposals/{proposal_id}/results")
        assert r.status_code == 200
        assert r.json()["tally"][0] == 1
```

## Errores comunes

- **`chain_id mismatch: esperado 57057, RPC dice 31337`**
  Faltó `monkeypatch.setenv("CHAIN_ID", "31337")` para tests en hardhat.

- **Hardhat node se rebootea entre tests**
  Para múltiples tests, usar fixture session-scoped o `--persistent`.
