## Por qué importa
Establece la base técnica para todo el backend, asegurando tipado y escalabilidad desde el inicio.

## Conceptos clave
- Node.js
- TypeScript

## Pre-requisitos
- Node.js ≥ 18
- npm

## Paso a paso
1. Ejecutar `npm init -y` en la carpeta backend.
2. Instalar TypeScript y dependencias básicas.
3. Inicializar tsconfig.json.

## Verificación / Definition of Done
- Proyecto Node.js inicializado.
- TypeScript configurado y compilando.

## Errores comunes
- No instalar TypeScript como devDependency.
- No crear tsconfig.json.
